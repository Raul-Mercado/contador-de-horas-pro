# Control Horas Pro

## Descripción
Control Horas Pro es una aplicación de escritorio desarrollada en Python para gestionar el control de horas trabajadas. Permite registrar jornadas, gestionar usuarios, generar informes y exportarlos en varios formatos.

## Características
- Gestión de múltiples usuarios con configuración individual.
- Reloj y cronómetro para seguimiento automático de horas.
- Registro manual y edición de entradas.
- Generación de informes y exportación a Excel y TXT.
- Impresión directa en Windows con diálogo nativo.
- Menú de ayuda con tutorial y datos del desarrollador.
